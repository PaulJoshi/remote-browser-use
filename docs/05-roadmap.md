# 05 — Roadmap

Security is part of the first working tool. Do not build a remotely accessible browser endpoint first and bolt OAuth on afterward. Each phase includes unit and integration tests; do not call a phase complete because an untested mock returns success.

| Phase | Build | Exit criteria |
|---|---|---|
| **0 — Feasibility and foundations** | Recheck npm name and latest MCP/auth/client docs; validate separate admin port, forwarded OAuth discovery, Playwright's isolated profile and browser install on macOS; initialize TS ESM package with `bin`, lint/typecheck/Vitest, fixture and CI | `npm pack --dry-run` contains no secrets or browser profiles; a locally launched browser and authenticated MCP Inspector handshake using a configured test HTTPS URL work without any public admin route |
| **1 — Secure vertical slice** | CLI first-run/setup, OAuth + protected Streamable HTTP, public-URL setup, owner admin authentication, `requestTabAccess`, client/tab/tool/origin policy, `listTabs` and `readPage`, metadata-only audit and revoke-all | Cloud connector through a Public HTTPS forwarded MCP port reads **only** a locally granted tab; ungranted tab and unauthorized client fail; admin port remains private |
| **2 — Browser, frames and read tools** | Persistent profile, tab lifecycle and refs, navigation/new-tab grants, frame-aware snapshots and screenshots, bounded outputs, no-login fake training site with a cross-origin frame | Read-only demo works after restart and frame access is denied until separately granted; redirects, popups, and stale refs cannot bypass scope |
| **3 — Interactions and approvals** | Click, hover, drag, typing/keys, dialogs, downloads/uploads policy, sensitive-action queue, visible control indicator and kill switch | Agent completes the entire bundled fictional training flow, including the iframe and quiz; password entry/submission/revocation tests fail closed without approval |
| **4 — Compatibility and hardening** | Current MCP version plus client-required legacy revisions; rate/size limits, host/origin/CSRF tests, browser install/restart/error handling, macOS and second-OS smoke tests | Test with MCP Inspector and a real Claude web connector, and ChatGPT where account support exists; report precise client/OS/browser versions and any limitations |
| **5 — Release readiness** | Thorough README/user onboarding, package `files`/bin/engine metadata, clean-install `npx` test, license and repository details after owner choice, CI verification and publishing instructions | Owner reviews test evidence and tarball; publish only after explicit owner approval using `docs/06-publishing.md`; verify the published version with a clean-machine `npx` run |
| **Later, separate designs** | Existing signed-in Chrome tabs via separately consented extension or browser-wide Chrome 144+ debugging (different threat model); optional stdio client transport, other browsers | Not advertised as a v1 capability; `runPlaywrightCode` remains unavailable without a new security design |
